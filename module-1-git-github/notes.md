## Key vocabulary (in your own words)

- repository: is folder where you save your files or project
- commit: is checkpoint where you made a change
- branch: s a separate copy of the main project where you can do all you want without affecting the main project
- push / pull: Push is uploading your changes. Pull is getting the current changes on the github
- pull request: is a like when you want to add your changes from one branch into another branch.
- merge conflict: is when two people change the same line
